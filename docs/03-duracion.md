# Bloque 3 · Calcular y decidir sobre una canción

- `04-duracion.php`: `intdiv($duration, 60)` y `$duration % 60` (185 → 3 minutos y 5 segundos).
- `05-estado-cancion.php`: «Sin duración» (0), «Hasta cuatro minutos» (1-240), «Más de cuatro minutos» (>240).
- `0 === '0'` es false porque `===` compara valor y tipo.
